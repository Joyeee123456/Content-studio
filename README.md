# Content Studio AI Demo

## 本地运行

需要 Node.js 18 或更高版本。

1. 在 TokenHubCloud 获取模型 API Key，并在 SocialCrawl 获取数据 API Key。请勿将 Key 发到聊天或写进网页前端。
2. 在项目目录复制 `.env.example` 并命名为 `.env`，分别填写 `LLM_API_KEY` 和 `SOCIALCRAWL_API_KEY`。`.env` 已加入 `.gitignore`。
3. `LLM_BASE_URL` 默认是 `https://api.tokenhubcloud.net/v1`；如需更换模型，修改 `LLM_MODEL`，并确认该模型对你的网关账户可用。
4. 在项目目录运行：

   ```bash
   npm install
   npm start
   ```

5. 打开 `http://localhost:3000`。不要直接双击 `index.html`，AI 分析需要后端进程运行。
6. 可访问 `http://localhost:3000/api/health` 查看服务是否启动、是否检测到 API Key，以及当前使用的 Base URL。此接口不会返回密钥。

## 部署

正式上线需要将网站和 Node.js 后端部署到支持 Node 服务的托管平台，并在平台的环境变量 / Secrets 设置中添加 `LLM_API_KEY`、`LLM_BASE_URL` 和 `LLM_MODEL`。部署平台尚未确定，当前项目可先在本地验证。

## 自动趋势与评论洞察

选择 TikTok 后，商家只需填写目标市场、品类和品牌 / 产品资料，并选择重点消费者需求及要生成的内容类型。服务端先让模型生成两个目标市场语言的产品搜索词，再使用 SocialCrawl 查询该市场的品类热门标签、当月相关视频，并读取最多两个相关视频的首批公开评论。采集到的最多 40 条评论先由模型依据所选需求筛选；筛选结果中的表达词只有在至少两条评论原文中出现、且服务端核实确实存在时才会作为重复表达展示。最终生成模型只会收到筛选后的评论、经核验的重复表达、趋势标签、品牌资料和所选内容类型。页面显示采集数、筛选数、情绪和主题统计、表达词、数据来源及 SocialCrawl credits 用量。

每次分析最多查询 1 个热门标签榜、2 个搜索结果页和 2 个评论页；搜索与评论请求各限制为最多 1 credit。热门标签榜的实际费用以接口响应为准：本项目验证时返回 6 credits，因此一次未命中缓存的分析预计最多约 10 credits。页面显示接口实际返回的 credits 用量。市场筛选以数据源返回的视频地区为准；没有符合地区的视频时，评论数可能为 0。当前自动采集只接入 TikTok；其它平台只根据输入资料生成内容。趋势标签和评论是有限公开样本，不代表全平台或完整市场。

## 能力边界

模型服务会收到品牌 / 产品资料、需求重点、趋势数据及最多 40 条采集评论用于筛选；最终内容生成只接收通过筛选的评论与核验后的表达词。筛选会额外产生一次模型调用和相应费用、等待时间。SocialCrawl 收到搜索词和目标市场。请勿输入不应发送给这些第三方服务的信息。该集成调用 SocialCrawl API，费用按其服务条款和账户定价结算；只展示汇总洞察和来源视频，不提供评论原文导出。

## 隐私与安全

- API Key 只由 Node.js 后端从环境变量读取，不会发送到浏览器。为兼容现有本地配置，后端也会读取 `OPENAI_API_KEY`，但新配置建议使用 `LLM_API_KEY`。
- `.env` 不应提交到 Git 或上传到静态网站目录。
- 用户输入会发送到配置的模型服务以完成生成；不要输入不应传给第三方服务的敏感信息。
- 为筛选评论，采集到的评论原文会发送给配置的模型服务；最终生成只使用筛选后的评论。
- 上线前应配置调用限额、访问控制和监控，避免公开接口被滥用。
